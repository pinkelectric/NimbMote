# Deskora brand direction

Deskora is the public product name. It is short, neutral and describes a bridge
between a desktop and the devices around it without borrowing another brand's
identity.

## Mark

The mark is a deep-plum rounded tile with two lilac desktop/device frames and a
single connection point between them. It must stay simple enough to recognise
at Android launcher and Windows tray sizes.

## Compatibility note

The current Android package ID, Windows executable name, configuration folder
and encrypted wire protocol retain their legacy BentleyRemote identifiers for
the v0.7.0 transition. They are implementation identifiers only and are not
user-facing. Changing Android's package ID will be a separate pre-Play release
because it creates a new installation and requires re-pairing.
